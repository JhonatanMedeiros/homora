# Support

For installation and everyday use, start with the [user guide](docs/user-guide/README.md) and search existing issues for similar questions.

To report a bug or suggest an improvement, open an issue using the relevant template. Include the Homora version and a minimal example when useful; do not include credentials, private addresses, personal information or real infrastructure screenshots.

Report a suspected vulnerability privately using the instructions in [SECURITY.md](SECURITY.md), not a public issue. For contribution guidance, see [CONTRIBUTING.md](CONTRIBUTING.md).

Homora is an early-stage project maintained on a best-effort basis; there is no guaranteed response time.
