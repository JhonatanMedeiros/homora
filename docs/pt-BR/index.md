## Encontre o que precisa

- **Primeira vez?** Siga os [primeiros passos](user-guide/getting-started.md) para instalar e adicionar um serviço.
- **Já possui uma configuração?** Veja como [importar, exportar e fazer backup](user-guide/import-export-backup.md).
- **Acesso por outros dispositivos?** Leia [instalação e atualizações](user-guide/deployment.md) e [conta e segurança](user-guide/accounts-and-security.md).
- **Quer contribuir?** Consulte o [guia de contribuição](contributing.md).

O Homora está em desenvolvimento inicial e foi projetado para acesso local. Os guias indicam recursos experimentais e validações pendentes.
