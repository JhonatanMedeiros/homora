# Contribuindo com o Homora

Você pode contribuir relatando problemas, sugerindo melhorias, escrevendo documentação ou propondo código.

1. Leia o [guia de contribuição no GitHub](https://github.com/JhonatanMedeiros/homora/blob/main/CONTRIBUTING.md) para configurar o ambiente e conhecer os testes e o processo de pull request. O guia está em inglês.
2. Consulte os [padrões de engenharia](/standards) e a [arquitetura](/architecture), também em inglês.
3. Para criar uma integração, siga o [guia do SDK](/adapters) e a [referência de integrações](/integrations).

## Skills para agentes de IA

Se você usa um agente de código, o repositório inclui skills opcionais para pull requests, integrações, widgets, migrações do banco e releases. Veja a [lista de skills no guia de contribuição](https://github.com/JhonatanMedeiros/homora/blob/main/CONTRIBUTING.md#ai-agent-skills), em inglês.

Respeite o [código de conduta](https://github.com/JhonatanMedeiros/homora/blob/main/CODE_OF_CONDUCT.md). Para relatar uma vulnerabilidade, use o canal privado indicado na [política de segurança](https://github.com/JhonatanMedeiros/homora/blob/main/SECURITY.md).
