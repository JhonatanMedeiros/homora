# Casos de uso

- **Organizar favoritos:** crie grupos e cartões para seus serviços ou [importe uma configuração](import-export-backup.md). Use a busca para encontrar rapidamente um endereço.
- **Acompanhar disponibilidade:** configure as verificações de cada serviço e um canal de alertas. Ajuste os limites para evitar notificações por falhas passageiras.
- **Compartilhar status:** habilite a [página de status](notifications-and-status-page.md) e escolha explicitamente os serviços visíveis.
- **Ver dados do Proxmox:** crie uma conexão de leitura e adicione widgets. O restante do Homora funciona sem ela.
- **Descobrir contêineres:** configure [descoberta Docker](docker-discovery.md), revise as sugestões e confirme somente as desejadas.
- **Usar um agente:** crie uma identidade com os menores escopos necessários e revise as propostas antes da aplicação.
- **Migrar de máquina:** teste um [backup e restauração](import-export-backup.md), incluindo as chaves necessárias.
